# Курсовая по ДОС и ЦФ

Программа для расчёта курсовой работы по методичке Каратаевой Н.А.
«Радиотехнические цепи и сигналы. Дискретная обработка сигналов и цифровая
фильтрация» (ТУСУР, 2002).

По номеру варианта и группе берётся шифр из таблицы А.1, дальше считается
первая часть (дискретизация сигнала) и вторая — синтез цифрового фильтра
по цепи-прототипу (буква А) или ФНЧ Баттерворта/Чебышёва по заданной АЧХ
(буквы Б и Ч).

## Как запустить

Открыть `app/index.html` в браузере. Ничего ставить не нужно, всё работает
без сервера и без интернета.

В разделе 0 выбрать вариант и группу и нажать «Решить всё». Там же две кнопки
для отчёта в Word:

- «Отчёт: часть 1 (.doc)» — записка только по первой части (пп. 2.1.1–2.1.6);
- «Полный отчёт в Word (.doc)» — обе части.

В отчёт попадают титульный лист, содержание, задание, расчёты с формулами,
таблицы, все графики и схемы фильтров, заключение и список литературы.
Содержание в Word обновляется по F9.

Файл сохраняется как .doc, который Word открывает без проблем. Если нужен
именно старый формат Word 97–2003, его можно пересохранить скриптом
(нужен установленный Word):

```bash
powershell -ExecutionPolicy Bypass -File app/v_doc.ps1 "Отчет_Вариант7_группа1.doc"
```

## Что где лежит

- `app/index.html` — интерфейс и весь расчёт;
- `app/schem.js` — редактор схем и узловой анализ цепи;
- `app/shemy_a3.js` — схемы из таблицы А.3 (пока внесены 11, 21, 31, 41, 51, 61, 12, 22, 32, 42);
- `app/otchet_doc.js` — сборка отчёта в Word;
- `app/v_doc.ps1` — пересохранение отчёта в формат Word 97–2003;
- `app/calc7.js` — отдельный расчёт чисел для варианта 7;
- `app/_pdftext.js` — вытаскивает текст из PDF методички;
- `app/test_*.js` — тесты.

## Тесты

Из корня проекта:

```bash
node app/test_varianty.js
node app/test_schemy.js
node app/test_signaly.js
node app/test_svg.js
```

`test_varianty.js` решает варианты 1–10 первой группы и сверяет результат
с расчётом, написанным отдельно по методичке. `test_schemy.js` проверяет K(p)
схем, `test_signaly.js` — формы сигналов, `test_svg.js` — что на схемах
фильтров линии не идут сквозь блоки.

## Как считается

Несколько мест, где методичку можно понять по-разному:

- Верхняя частота ωв — последнее пересечение уровня 0,1 от максимума |S(ω)|.
  Первое не подходит: дальше боковой лепесток снова выходит за порог.
- Порог считается от максимума |S|, а не от S(0), потому что у некоторых
  сигналов площадь нулевая.
- t₂ и Tc берутся по цифре N₂, а форма сигнала — по N₁.
- Отсчёты берутся во всех точках nTд < Tc; в точке скачка — значение после
  скачка, как в примере В.1. ДПФ считается по этим же отсчётам.
- Частота среза ФНЧ — ширина главного лепестка спектра сигнала (первый
  минимум |S| после максимума).
- Номиналы R, L, C в методичке не даны, по умолчанию стоят 1 кОм, 1 мГн и
  1 нФ. Их можно поменять в разделе 0.

## Известные проблемы

- Схема 61 не проходит тест: топология в коде не совпадает с рисунком
  на с. 49. В варианты 1–10 первой группы она не входит.
- У вариантов 4 и 10 с номиналами по умолчанию КИХ-фильтр по порогу 0,1
  получается нулевого порядка. Нужно увеличить L и C.
