# Решатель курсовой «Дискретная обработка сигналов и цифровая фильтрация»

Курсовая по методическим указаниям **Каратаевой Н.А.** (ТУСУР, 2002):
«Радиотехнические цепи и сигналы. Дискретная обработка сигналов и цифровая
фильтрация».

Расчётчик покрывает все три ветки задания по **таблицам А.1–А.4**:
30 вариантов шифров, 9 форм сигналов (А.2), 30 схем цепей (А.3) и
синтез ФНЧ Баттерворта или Чебышёва по параметрам АЧХ (А.4).

Один HTML-файл, без сборки, без сервера, без внешних библиотек.

---

## Запуск

Открыть в браузере двойным щелчком:

```
app/index.html
```

Никакой установки не требуется. Полная пояснительная записка по выбранному
варианту — кнопка **«📄 Полный отчёт в Word (.doc)»** в разделе 0: титульный лист,
содержание, задание, части 1 и 2 со всеми графиками и схемами, заключение,
список источников. Word открывает файл как обычный документ. Двоичный
.doc формата Word 97–2003 из него делает `app/v_doc.ps1` (см.
`ИНСТРУКЦИЯ_ЭКСПОРТ_DOC.md`). Печать страницы приложения в PDF — кнопка
«Печать / PDF».

## Разделы приложения

1. **0. Вариант (табл. А.1) + данные** — номер варианта, группа, E, t₁, R, L.
   Отсюда берётся шифр `N1N2 N3N4` и буква А/Б/Ч.
2. **1. Редактор схем цепи (тип А)** — рисование схемы мышью, расчёт K(p)
   из геометрии. Соединяются только **концы** элементов; пересечения без
   общей точки не соединяются.
3. **2. Часть 1 — дискретная обработка (п. 2.1)** — спектр, ωв, отсчёты,
   Z, ДПФ, восстановление, сравнения.
4. **2. Часть 2А — прототип + ЦФ (п. 2.2)** — для буквы А: K(p), g(t),
   билинейное и инвариантность, схемы ДФI/ДФII.
5. **3. Часть 2Б/Ч — ФНЧ по АЧХ (п. 2.3)** — для букв Б и Ч: порядок n,
   полюса, H(z), АЧХ/ФЧХ/импульсная характеристика.
6. **4. Отчёт по п.5 — выводы.**

Графики части 1 в порядке просмотра: `cvS` (спектр и ωв) → `cvФ` (фаза) →
`cvX` (отсчёты) → `cvDft` (|Cₖ|) → `cvArg` (arg Cₖ) → `cvRest` (восстановление) →
`cvОДПФ` (обратное ДПФ) → `cvCmp` (сравнение). Подробный разбор — в `объяснение_часть1.md`.

## Тесты

Запускаются из корня проекта:

```bash
node app/test_varianty.js   # варианты 1–10 гр. 1: ωв, x(n), ДПФ, K(p), ЦФ, Б/Ч — против эталона
node app/test_schemy.js     # 10 схем: K(p) против прямого узлового решения
node app/test_signaly.js    # 9 форм сигнала: S(0), max|S|, ωв, N_min — 0 провалов
node app/test_svg.js        # схемы ЦФ: нет линий сквозь блоки и дублей
```

Все должны показывать успех. Если `test_schemy.js` даёт 9 из 10 —
это известный сбой схемы 61, см. `app/DEVLOG.md`.

## Соглашения

- **ωв** берётся как **последнее** пересечение уровня 0,1·max вниз: по
  определению методички выше ωв модуль не превышает порога ни на одной
  частоте. Первое пересечение не годится — боковой лепесток поднимается
  до 0,13·max.
- **Порог ωв считается от max |S(jω)|**, а не от |S(0)|: у некоторых форм
  площадь сигнала равна нулю, и порог оказался бы нулевым.
- **Спектр считается аналитически** по формуле кусочно-линейного отрезка,
  а не численным интегрированием.
- **t₂ и Tc берутся из строки N2**, а не N1: номер формы и временные
  соотношения — независимые параметры шифра.
- **Отсчёты** — во всех точках nTд < Tc, N = ⌈Tc/Tд⌉ (В.1.2); в точке
  разрыва — значение справа от скачка. **ДПФ** берётся от той же
  последовательности (N = числу отсчётов); поле «N ДПФ» может только дополнить
  её нулями.
- **Ряд Фурье** — тригонометрический по В.1.5: C₀ + 2Σ|Cₖ|cos(2πkt/(NTд)+φₖ),
  k < N/2 (плюс член N/2 при чётном N).
- **Частота среза ФНЧ (Б/Ч)** — ширина основного лепестка спектра: первый
  минимум |S(ω)| за главным максимумом (В.5.1). Баттерворт: порядок по α на
  2ωЦ1 **и** β на 0…0,8ωЦ1; Чебышёв: ε = √(10^(0,1β)−1), полюса на эллипсе.
- **Метод инвариантности** — КИХ с порядком M по порогу 0,1 и рекурсивный ЦФ
  H(z) = d + ΣTд·cₖ/(1 − e^(pₖTд)z⁻¹); при K(∞) = d ≠ 0 учитывается
  δ-составляющая g(t).

## Открытые вопросы

1. **Схема 61** таблицы А.3 не проходит тест (падает одна из десяти).
   Согласно DEVLOG топология по коду неверна для этой схемы, требуется сверка
   с рисунком методички с. 49.
2. **Номиналы R, L, C** методичка не задаёт. По умолчанию R = 1 кОм,
   L = 1 мГн, C = 1 нФ (постоянные времени ≈ 1 мкс, как у сигнала). У вариантов
   4 и 10 при этих номиналах КИХ-фильтр по порогу 0,1 вырождается в порядок 0 —
   номиналы L и C стоит увеличить (В.4.5: Tд сигнала и ЦФ одинаковы).

Подробности по каждому пункту — в `app/DEVLOG.md`.
