ОШИБКА 1. ωв = 6,48 рад/мс — взято ВТОРОЕ пересечение, а не первое
-------------------------------------------------------------------------
Где: шаг 2, стр. 2.

Уровень 0,1·max кривая |S(ω)| пересекает ДВАЖДЫ:
    первое  — 3,9368 рад/мс
    второе — 6,4765 рад/мс
В документе стоит 6,48, то есть второе. По критерию п. 2.1.1 («частота, выше
которой модуль спектра не превышает 0,1 от максимума») берётся ПЕРВОЕ
пересечение: ωв = 3,94 рад/мс.

Почему это важно: ωв определяет и Тд, и все дальнейшие шаги. Ветки Б и Ч
опираются на ωц1 = 4,14 (первый минимум |S|) — он больше ωв = 3,94, и это
ещё не противоречие, но обоснование «минимум N = 7» из шага 2 становится
неверным (см. ошибку 3).

ОШИБКА 2. Неверная формулировка критерия в шаге 2
-------------------------------------------------------------------------
В документе: «Ищем последнюю частоту, где |S| > 0,15».
Правильно:  ищем ПЕРВУЮ частоту, на которой |S| становится МЕНЬШЕ 0,15.
«Последняя» как раз и даёт неверный ответ 6,48. Формулировка и есть причина
ошибки 1.

ОШИБКА 3. Вывод «минимальное N = 7» неверен
-------------------------------------------------------------------------
Где: шаг 2, стр. 2.

Документ: N = Tc/Тд ≥ 6,2, то есть минимум N = 7 (при ωв = 6,48).
С правильной ωв = 3,9368:  π/ωв = 0,7974 мс,  N ≥ 3,0/0,7974 = 3,76,
то есть минимальное N = 4, а не 7.

Выбор N = 12 и Тд = 0,25 мс при этом остаётся допустимым (запас по
теореме Котельникова только увеличивается), но обоснование «минимум N = 7»
надо заменить на «минимум N = 4».


ОШИБКА 4. Полюса Чебышёва не соответствуют β = 1 дБ (ветка Ч, шаг Ч3)
-------------------------------------------------------------------------
Где: шаг Ч3, стр. 7.

Документ приводит:  −0,494;  −0,247 ± j0,966.

Правильно при β = 1 дБ, n = 3:
    ε² = 10^(0,1·1) − 1 = 0,2589,   ε = 0,5088
    cosh(acosh(1/ε)/n) = 1,0949
    полюса: −1,0949;  −0,5474 ± j0,9482

Проверка: модуль полюсов документа = 0,9971. Обратным пересчётом это
соответствует ε ≈ 1,000, то есть β ≈ 3 дБ, а НЕ 1 дБ.

Из-за неверных полюсов неверны и все производные величины ветки Ч:
K(pн) = 0,49/(pн³ + 0,988pн² + 1,238pн + 0,49), K(z), коэффициенты
каскада 0,0441 / 0,5615 / 0,8445 / 0,6485, полюса |z| = 0,562 и 0,805,
а также g(n) и отклик в шаге Ч4. Их нужно пересчитать заново.

ОШИБКА 5. |K(ωц1)| = 0,707 (−3 дБ) не сходится с его же ωц1 (ветка Б, шаг Б4)
-------------------------------------------------------------------------
Где: шаг Б4, стр. 6.

В документе ωц1 = 4,14 и ωА1 = 4,554 (это разные частоты, и он сам их
различает). Но −3 дБ по определению Баттерворта достигается при ω = ωА1.

Проверка при ω = 4,14, ωА1 = 4,554, n = 3:
    |K| = 1/√(1 + (4,14/4,554)^6) = 0,7995  →  −1,94 дБ, а НЕ −3 дБ.

Это внутреннее противоречие: заявленный «контроль −3 дБ ✓» не выполняется.
Чтобы он выполнялся, нужно либо проверять на частоте ωА1 = 4,554, либо
определять ωц1 именно как ωА1.
